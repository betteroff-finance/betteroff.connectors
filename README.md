# BetterOff connectors

Connect your AI client to [BetterOff](https://betteroff.finance/github) to review household finances, find recurring charges, and prepare corrections for your approval.

**39 tools (bank transfers not available yet) · 11 skills · 11 client setup guides** · [![Audit](https://github.com/betteroff-finance/betteroff.connectors/actions/workflows/audit.yml/badge.svg)](https://github.com/betteroff-finance/betteroff.connectors/actions/workflows/audit.yml)

[Quickstart](#quickstart) · [All clients](#install-the-connector) · [Tool reference](docs/tools.md) · [Connector reference](docs/connector.md) · [Security](SECURITY.md)

## Before you start

- **Account:** You need a BetterOff household owner account and a client listed below. To ask about your finances, first connect a supported financial account or wallet in BetterOff.
- **Plan:** Tools work on every plan, including Free, over MCP or REST. Some tools need the Better plan and return `CORE_REQUIRED` on Free. Insurance needs the Best plan, which is in early access.
- **Consent:** Every household member must turn on **Chat data access** in BetterOff settings, and you must accept the applicable BetterOff Terms. Your connected client receives the data that each tool returns.
- **Approval:** The connector prepares corrections for your review. If you grant the transfer scopes, it can also request wallet transfers and vault deposits. You review each request in BetterOff, and each requires your wallet signature. Bank transfers are not available yet. The connector cannot apply a correction or approve or execute a request.

The [tool reference](docs/tools.md) lists each tool and the scopes it requires.

## Quickstart

### Claude Code

1. Run these commands in a terminal:

   ```sh
   claude plugin marketplace add betteroff-finance/betteroff.connectors
   claude plugin install betteroff@betteroff
   ```

2. Start a new Claude Code session and run `/mcp`.
3. Select `betteroff` and sign in to BetterOff.

### Codex

1. Run these commands in a terminal:

   ```sh
   codex plugin marketplace add betteroff-finance/betteroff.connectors
   codex plugin add betteroff@betteroff
   ```

2. Start a new Codex session and complete the BetterOff sign-in prompt.

### Other clients

- **MCP clients with OAuth:** Add `https://api.betteroff.finance/mcp` as a remote server with Streamable HTTP transport and OAuth sign-in.
- **Clients without OAuth:** In BetterOff, open **Settings** > **API tokens** and create a token. Then call the same tools over REST at `POST https://api.betteroff.finance/v1/tools/{name}`. See the [developer documentation](https://betteroff.finance/developers) and the [tool OpenAPI document](https://api.betteroff.finance/openapi/tools.json).

### Check the connection

After you sign in, ask: “Show my household overview and flag missing or out-of-date data.” The answer should name your household and include dates or missing-data warnings.

## What BetterOff records

This repository contains no telemetry code. The connector sends nothing from your computer except your requests to BetterOff. When your client calls a tool, BetterOff's servers log the tool name, whether it succeeded, the error code if it failed, how long it took, how many records it returned, the client's name and version, and hashed household and connection identifiers. The logs do not contain your prompts, the tool arguments or results, or your financial data. Selected logs are archived for 30 days. The [BetterOff Privacy Policy](https://betteroff.finance/legal/privacy) has the full list and retention periods. You can disconnect at any time in BetterOff under Settings > Agent connections.
